Algorithm — Random Forest

Ensemble classifier

What it is

An ensemble of 100 independently trained decision trees. Each tree is built on a random subset of patients (bootstrapping) and a random subset of features at each split. Final prediction is by majority vote.

Why Random Forest over Logistic Regression

RF outperformed Logistic Regression, KNN, SVM, Decision Tree, and XGBoost on Recall — the primary metric for medical screening. It handles non-linear feature relationships and feature interactions without requiring additional engineering.

35% Threshold Justification

Clinical safety decision

The Core Problem

Default threshold (50%): Recall = 89.2%. But in cardiac screening, a False Negative — classifying a sick patient as healthy — is far more dangerous than a False Positive.

The Fix

Lowering to 35%: Recall rises to 91.2%. We catch 2 additional sick patients per 184 tested, at the cost of a small increase in precautionary referrals. This trade-off is standard in medical screening protocols (mammography, cardiac enzymes).

Key Data Cleaning Decisions

Notebook 02 — critical preprocessing steps

Cholesterol = 0 (n≈172 patients)

A human cannot have 0 mg/dL cholesterol. These were missing values encoded as 0 during dataset merging across 5 hospital cohorts. Solution: replaced with the median of non-zero values (not mean — distribution is right-skewed). Median computed on non-zero values only. This preserved all 172 rows rather than dropping ~18% of the dataset.

RestingBP = 0 (n=1 patient)

Same logic — physiologically impossible. Replaced with non-zero median. One row, negligible impact but corrected for data integrity.

Outliers — Kept Intentionally

Cholesterol values up to 603 mg/dL and Oldpeak up to 6.2 mm are extreme but medically real — severely ill patients genuinely have these values. Removing them would bias the model away from the very patients most at risk.
