Project Overview

What this is and what it is not

What This Project Is

CardioRisk is a full-stack machine learning portfolio project demonstrating the complete workflow from raw clinical data to a deployed prediction API with a professional web interface. It covers exploratory data analysis, data cleaning, feature engineering, model selection across 8 algorithms, hyperparameter tuning, threshold optimisation, and production deployment via FastAPI on Render with a static frontend on Vercel.

What This Project Is NOT

This is not a licensed medical device. It has not undergone clinical validation, regulatory review (FDA, CE, CDSCO), or peer-reviewed external audit. The model was trained on a publicly available research dataset. It must not be used to make or influence any real patient care decision.

Dataset Source

UCI Heart Disease Dataset — combined Cleveland, Hungarian, Switzerland, Long Beach VA, and Statlog cohorts. 918 patients, 12 features, binary classification target. Accessed via Kaggle (fedesoriano, 2021).
